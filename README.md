# HTML 游戏合集

经典小游戏的纯 HTML/CSS/JavaScript 实现，打开即玩，无需安装。

## 🎮 游戏列表

| 游戏 | 文件 | 说明 |
|------|------|------|
| 2048 | `2048.HTML` | 经典数字合并游戏 |
| 贪吃蛇 | `贪吃蛇.html` | 基础版贪吃蛇 |
| 人机版贪吃蛇 | `人机版贪吃蛇.html` | AI 对战版贪吃蛇 |
| 人机版贪吃蛇2 | `人机版贪吃蛇2.html` | AI 对战版贪吃蛇（进阶版） |
| 俄罗斯方块 | `俄罗斯方块.html` | 经典俄罗斯方块 |

## 🚀 使用方法

1. 克隆仓库或下载 ZIP
2. 用浏览器直接打开任意 `.html` 文件即可开始游戏

```bash
git clone https://github.com/go-farther-and-farther/html_game.git
```
