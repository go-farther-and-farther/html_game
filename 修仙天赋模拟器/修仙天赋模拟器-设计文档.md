# 《测灵台 · 修仙天赋模拟器》设计任务书

> 本文档是完整的设计规格，交给任何 agent 都应能独立产出一版功能一致的单文件 HTML 网页游戏。
> **视觉风格不在本规格约束范围内**：配色、字体、动效、布局由实现者自由发挥，只要求功能齐全、信息清晰。

---

## 一、项目概述

一个修仙题材的**天赋随机模拟器**：用户点击"测灵"，模拟一个人的修行天赋——先掷出"五行总天赋"分数，再把分数拆成灵子分配到金木水火土五系灵根上，给出品级判定、评语和统计信息。

核心页面功能（共 5 个区块）：

1. **参数区**：可调参数（见第五节），参数变化时实时刷新概率提示。
2. **测灵区**：单次"测灵"按钮（带简短的滚动出分过程即可，形式不限）+ "批量模拟一百万次"按钮。
3. **统计区**：批量模拟后的统计卡 + 总天赋分布直方图（0~10 按整数分桶）。
4. **排行榜**：单灵根峰值榜（规则见第七节，**注意有明确的准入口径，见"决策记录"**）。
5. **历史区**：最近 8 次单次测灵的记录（编号、天赋、总评）。
6. 页脚用一段话写清当前规则与品级线。

---

## 二、五行总天赋（核心数值，必须逐条满足）

这是整个项目最重要、也经历了多次修正的部分，**最终方案如下，不要回退到任何中间方案**：

```
取 4 个 [0,1) 均匀随机数，升序排序，取第 2 小的 u
总天赋 talent = round1( max(0.1, 10 × u) )    // round1 = 四舍五入到 0.1
```

数学性质（这是选择它的全部理由，实现后必须用大样本验证）：

- 等价于 **Beta(2,3) 分布 × 10**（次序统计量：n 个均匀随机数中第 k 小的均值恒为 k/(n+1)，此处 2/5）。
- **100% 落在 0~10 之间**（由构造保证，不靠截断概率尾巴）。
- **平均值恰好等于 4.00**（不是"大约"）。
- 钟形**右偏**：峰在约 3.3，庸才居多、天才向 10 拖出长尾。整数分桶占比约为：
  `5.2 / 12.9 / 16.8 / 17.7 / 16.3 / 13.3 / 9.6 / 5.7 / 2.4 / 0.4`（0~9 桶 + 9~10 桶）。
- **0 是身份，不是分数**：普通人生的天赋下限 0.1；总天赋为 0 的唯一可能是"绝灵体"（见第三节）。
- **没有任何机缘/暴击类加成**。早期版本有"1% 概率 +1 可无限叠加"的指数级机缘，已被明确移除，不要加回。

### 天赋文字定级（按分位划档，占比为该分布下的理论值）

| 分数 | 评语 | 占比 |
|---|---|---|
| ≥ 9 | 天纵奇才 | ~0.4% |
| ≥ 8 | 道基深厚 | ~2.7% |
| ≥ 6 | 良才美质 | ~18% |
| ≥ 3 | 资质平平 | ~47% |
| ≥ 1 | 根骨驽钝 | ~30% |
| < 1 | 凡俗之躯 | ~5% |

---

## 三、灵根判定与绝灵体

测灵时先做一次**灵根存活判定**：金木水火土五系灵根，每系**独立 10% 概率失效**。

- **全部失效 ⇒ 绝灵体**：五系全空，总天赋显示为 0（全场唯一允许的 0），评语"绝灵体"。
- 有存活灵根 ⇒ 进入灵子分配（第四节）。

---

## 四、灵子分配（总天赋 → 五系分数）

总天赋以 **0.1 为一粒"灵子"** 拆成整数粒（`grains = talent × 10`），分两段落到五系：

1. **第一段（平分）**：一半灵子（向下取整）**平均分**给所有存活的灵根（整数粒均分，余数逐系轮流+1）。这一段保证每系都有基本盘。
2. **第二段（偏好依附）**：剩下的灵子逐粒随机分配。每粒落系时按权重抽取，权重 = `该系吸附值 + α × 该系当前分数`；每落一粒，该系分数 +0.1、权重随之 +α——**强者愈强**，模拟"火旺之地火亲和者愈聚灵"。

参数含义见第五节（α 与各系吸附值）。

### 单系分数的结构性上限

由于第一段平分，单系最多约吃到总天赋的六成；总天赋均值 4 的世界里，单系 3.5+ 已属罕见高分。这是**有意设计**，不要"修"它。

---

## 五、品级体系与可调参数

### 品级线（自动插值）

用户只调两个阈值，中间品级线自动四等分插值：

```
step = (天灵根线 − 废灵根线) / 4
下品线 = 废灵根线 + step        （默认 1.5）
中品线 = 废灵根线 + 2×step      （默认 3.0）
上品线 = 废灵根线 + 3×step      （默认 4.5）
```

单系分数与品级线比较（注意边界：废灵根是"大于"，其余是"≥"）：

| 条件 | 判定 |
|---|---|
| 分数 > 废灵根线 | 废灵根（**废灵根 = 凡人，不能修行**） |
| ≥ 下品线 | 下品灵根 |
| ≥ 中品线 | 中品灵根 |
| ≥ 上品线 | 上品灵根 |
| ≥ 天灵根线 | 天灵根 |

### 可调参数（滑块或等价控件）

| 参数 | 默认 | 范围 | 作用 |
|---|---|---|---|
| 偏好依附 α | 1.0 | 0.1~2 | 灵子第二段分配的强者愈强系数 |
| 废灵根线 | 0.0 | 0~9 | 分数 > 此值即为废灵根；插值基点 |
| 天灵根线 | 6.0 | 1~10 | ≥ 此值为天灵根；插值基点（不得低于废灵根线，联动约束） |
| 五行吸附值 ×5 | 1.0 | 0.5~5 | 各系初始权重，"火旺之地把火调高" |

## 六、总评命名（品质制，非数量制）

总评标题**按最高灵根的品质**命名，**不使用**"单灵根/双灵根/三灵根"这类数量命名（数量信息放描述里）：

1. 绝灵体（五行灵根尽数失效，总天赋 0）
2. **凡 人**——连下品都没有（无灵根，或五行俱为废灵根）。"废灵根的是凡人"是明确需求。
3. 下品灵根 / 中品灵根 / 上品灵根——标题取最高一系的品级；身怀多系时在描述里注明"身怀 N 系灵根"，并说明主修（最高）系。
4. 天灵根 · X（恰一系）/ 多系天灵根 · XX（两系以上），X 为元素名。

## 七、统计、排行榜与历史

### 统计卡（批量模拟一百万次后刷新）

平均天赋 ｜ 最高天赋 ｜ 身负灵根者（≥下品）｜ **下品灵根者**（有下品、但无任何中品及以上，即"峰值止步下品"的人数）｜ 中品及以上 ｜ 上品及以上 ｜ 天灵根 ｜ 绝灵体 ｜ 凡人（无下品灵根）。

**口径要求**：绝灵体、凡人、身负灵根者三类**互斥**且加总 = 总人数；其余为其中的细分/累计。

### 排行榜：「单灵根 · 峰值榜」（有明确决策，勿改）

- 准入：**恰好一系**灵根 ≥ 下品线，其余四系全是废灵根或无灵根。
- **不限品级**：该系哪怕是中品、上品、天灵根都能上榜。
- 按该系分数排名，保留前 10；显示元素系别、分数、编号与总天赋。
- ⚠️ 历史教训：曾错误地把准入改成"峰值止步下品"（排除中品以上），导致榜单被 2.9（中品线 3.0 − 0.1）刷屏封顶。**不要重犯**。

### 概率提示

参数每变化一次，用蒙特卡洛（约 10 万次）实时估计并展示：身负灵根（≥下品）、中品及以上、上品及以上、天灵根的概率（概率极小时显示"1/N"形式）。

### 直方图

总天赋按整数 0~10 分桶画柱状图。

## 八、设计理念（用户的核心诉求，实现取舍时以此为准）

1. **范围由构造保证**：随机分布必须 100% 落在设计区间内——优先用数学性质（如次序统计量）实现，而不是"超界就裁剪"。
2. **均值精确可控**：平均值要恰好等于设计值（当前为 4），不是近似。
3. **右偏的现实主义**：庸才占绝大多数，天才是长尾上的极少数；**拒绝任何指数级运气堆叠机制**。
4. **0 是身份**：总天赋 0 只属于绝灵体。
5. **品级即修行资格**：废灵根者视为凡人；命名按品质（下/中/上/天），不按灵根数量。
6. **口径分离**：统计卡可以按品级定义（"下品灵根者"= 峰值止步下品），但排行榜保持"单灵根"本意（恰好一系达标，不限品级）——两者不是一回事。
7. **参数可调**：偏好依附、两条阈值线、五行吸附都暴露给用户，品级线自动插值。
8. **数值必须可验证**：交付前跑大样本（≥30 万次）断言测试，见下节。

---

## 九、验收标准（数值断言，交付前必须全绿）

用 Node 提取页面脚本 + 最小 DOM 桩即可测，建议断言：

1. 非绝灵体的总天赋 100% ∈ [0.1, 10]；绝灵体总天赋 = 0 且唯一。
2. 总天赋均值与 4 的偏差 < 0.05（30 万样本）。
3. 整数分桶占比与第二节理论值吻合（±1% 内）。
4. 绝灵体 + 凡人 + 身负灵根者 = 总样本数。
5. "无下品灵根（且非绝灵体）⇔ 总评=凡人"；品级标题与最高单系分数一致。
6. 排行榜：≤10 条、降序、每条分数 ≥ 下品线、榜首分数 = 全场"恰一系达标者"的单系最高分。
7. 天灵根评语路径不报错（历史版本曾因未定义变量在此崩溃）。

## 十、决策记录（踩过的坑与最终澄清，防止回退）

| 议题 | 结论 |
|---|---|
| 机缘加成 | 初版"1% 概率 +1 可叠加"已**移除**，不要加回 |
| 分布方案演进 | N(5,1.2)+机缘 → N(6,2) → 截断 0~8 再 +2 → **最终：Beta(2,3)×10**；以最终版为准 |
| "单灵根改成下品灵根" | 仅指**统计卡**命名（单灵根者→下品灵根者）；**排行榜**仍叫"单灵根·峰值榜"且不限品级 |
| 排行榜 2.9 封顶 | 根因是把准入改成"止步下品"；正确准入是"恰好一系 ≥ 下品" |
| 天灵根评语 | 曾因未定义变量 `names` 在该分支崩溃，务必自测 |
| 概率截断 vs 重采样 vs 次序统计量 | 前两者会造成端点堆积或仍有越界概率，次序统计量法天然规避 |
