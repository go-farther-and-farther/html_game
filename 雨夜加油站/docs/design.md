# 雨夜便利店街角 · 三渲二微缩场景 — 设计文档

日期:2026-09-25 · 交付物:单个自包含 `index.html`(Three.js r160,CDN importmap)

## 需求(来自用户,已视为批准的设计输入)
- 第三视角、可自由拖拽/旋转/缩放的微缩三维街角,像可收藏的小型景观模型,无任何 UI 元素。
- 完整正方形底座,所有元素建于其上,便利店位于视觉中心,构图紧凑、层次清晰。
- 三渲二(cel/toon)风格:清晰轮廓线、干净材质、柔和色彩 + 夜景霓虹层次。
- 街角要素:招牌、玻璃橱窗、自动门、雨棚、地垫、自动贩卖机、自行车、雨伞架、垃圾桶、
  路灯、电线杆/电线、路牌、护栏、停车位、排水沟、积水路面、反光斑马线、小巷入口、
  空调外机、公告栏等。
- 店内可见且充实:货架、饮料柜、便当区、饭团零食、收银台、咖啡机、杂志架、海报、
  灯箱、冰柜、关东煮柜台、地面导视、储物柜/后场门;店内明亮温暖 vs 室外冷暗雨夜。
- 动效:持续降雨、屋檐滴水、积水波纹、招牌/灯箱轻微闪烁、自动门偶尔开合、雨水沿玻璃
  滑落、积水反射灯光、远处信号灯微弱变化。

## 技术方案
- 单文件 HTML + ES module importmap(three@0.160.0, jsdelivr)。
- 渲染:ACES 色调映射 + EffectComposer(RenderPass → UnrealBloomPass → OutputPass),
  霓虹辉光;线性雾;渐变夜空背景 + CSS 暗角(非 UI 装饰)。
- 三渲二:MeshToonMaterial(4 阶 RedFormat 渐变图)+ 所有 toon 材质注入 rim 暗边
  (onBeforeCompile,基于视角-法线 fresnel);主体(建筑、招牌、贩卖机、路灯、电线杆等)
  另加 inverted-hull 黑色轮廓。
- 湿路面:自研 `WetReflector` — 平面反射(镜像相机 y=2h−y,textureMatrix=P·V·M),
  768² 渲染目标;片元:底层路面贴图透过(透明混合),反射叠加 + 菲涅尔增强;
  12 个活动涟漪槽(vec4 数组 uniform:圆心/出生时间/强度)产生环形 UV 扭曲 + 全局细微波纹。
- 地面:2048² canvas 烘焙整个底座顶面(人行道地砖、双条道路、中央虚线、边线、
  两处斑马线、停车位+P 标、排水沟格栅、井盖、小巷地面、黄色导盲条)。
- 雨:两组 LineSegments(远景 800 条淡、近景 260 条亮),下落回绕。
- 滴水:屋檐/屋顶 6 个滴点 → 雨滴小球 + 落地水花环 + 写入涟漪槽;路面随机落点涟漪。
- 玻璃雨痕:512 类 canvas(256×1024)动态纹理,destination-out 淡出 + 下落水滴拖尾,
  贴在南北玻璃外侧。
- 自动门:12s 周期开合(缓动);招牌/灯箱/贩卖机屏:噪声+随机 dropout 闪烁;
  远处红绿灯:9s 红黄绿弱变化;关东煮:蒸汽 sprite 循环;路灯/店铺:地面光晕(加法混合)。
- 店内:instanced 商品(货架盒 ~420、饮料罐 ~160、便当 ~100、杂志 ~36),
  冷藏柜暖/冷发光背板、吊灯盒、地面导视、卷帘门、储物柜。
- 灯光:半球光(冷)+ 月亮平行光(冷、投影)+ 5 个点光(店内暖×2、路灯暖、
  贩卖机冷、小巷冷);发光件用 MeshBasicMaterial 高倍色彩进 bloom。

## 构图(底座 120×120,单位≈米)
- 便利店:x −28..12, z −28..12(视觉中心偏西北),东南角 (12,12) 正对路口。
- 街角:东西向道路 z 20..38;南北向道路 x 20..38;交叉口 x/z 20..38;
  两条斑马线贴店角(L 形)。
- 东侧地块 x 38..58:停车位(4 格)、路灯、电线杆×2(电线沿线+引下线到店顶)、路牌。
- 店西侧小巷 x −36..-28:空调外机、日光灯管、海报、暗巷入口。
- 入口区:雨棚、自动门、地垫、雨伞架、自行车+停车架、垃圾桶、公告栏、斑马线前护栏。
