# 元素哨站 V6 设计文档

日期：2026-08-27 · 前置：elemental_outpostV5.html · 产物：elemental_outpostV6.html（单文件，沿用全系列惯例）

用户决策：方案 A 全家桶整合版——先修 V5 bug，再全面加功能，删减权授予实现方。已确认全部 6 节设计。

## §1 基础设施

### 存档迁移
- 新 key 族：`elementalOutpost.v6`（存档）/ `.settings` / `.best` / `.legacy`。
- 首次启动一次性从 v5 迁移：主题、速度、难度、lastLevel、各关最佳波次。v5 键保留不删。
- 存档结构在 v5 基础上新增：
  - 塔：`{type,x,y,level,strategy}`
  - 游戏状态：`energy`（技能能量）、`career`（生涯积分）、`barrier`（核心护盾余量）

### Bug 修复
1. 毒杀绕过结算：Enemy.update 的 DOT 致死分支不再静默返回；死亡结算集中到 Game 层——敌人更新循环后统一扫描"alive=false 且未 leak 且未结算"的敌人调 kill()。毒死的分裂者正常分裂/加分/爆特效。
2. rHover 边界判断 `r>=COLS` 改为 `c>=COLS`。
3. 破盾溢出伤害丢失：hurt() 先扣盾、剩余落到 HP；返回值仍表示是否致死。
4. 坐标换算去重：pointermove/pointerup 共用一个 toXY(e) 映射。

## §4 索敌策略

- per-tower 字段 `stgy ∈ {first,last,strong,near}`，默认 first；选中塔面板显示循环切换按钮；随存档持久化。
- last=射程内进度最小者；strong=当前HP(含盾)最高；near=距塔最近。
- 激光塔固定锁定全图进度最深者，不受策略影响。磁暴固定取最靠前。
