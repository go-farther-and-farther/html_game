# 元素哨站 V7 选关缩略图改进设计

## 问题

选关卡片顶部目前只绘制纯色矩形。高分辨率下，这些区域面积很大，却没有路线、地形或战斗信息，因此看起来像未加载的空占位框。

## 设计

- 保持单 HTML、无外部图片依赖，使用 Canvas 程序化绘制缩略图。
- 每张缩略图复用对应关卡的真实路径数据，并按预览区域缩放。
- 缩略图包含棋盘格地形、发光路线、入口、核心、三座炮塔和若干敌军点位。
- 四张图使用各自关卡配色，并增加渐变暗角、地图编号和路线长度标签。
- 卡片整体收紧纵向留白，强化标题、描述、生命倍率和难度星级的视觉层次。

## 验收

- 四张卡片均调用真实缩略图绘制方法，不再出现纯色空框。
- 缩略图路线来自 `MAPS[i].pts`，与实际关卡布局一致。
- 选关点击热区和键盘 1—4 操作保持不变。
- 4K、常规桌面和窄屏布局均能正常显示，原有行为测试与平衡测试全部通过。
