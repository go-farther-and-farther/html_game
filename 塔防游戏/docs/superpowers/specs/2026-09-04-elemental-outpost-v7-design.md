# 元素哨站 V7 设计规格

日期：2026-09-04  
基线：`elemental_outpostV6.html`  
目标产物：`elemental_outpostV7.html`

## 1. 产品目标

V7 是 V6 的策略增强版本。它继续保持“单个 HTML、离线运行、零外部依赖”的形态，保留 13 种塔、15 种敌人、4 张地图、主动技能、索敌策略和生涯系统，同时解决 V6 的续局、早期数值、操作层级和后期性能问题。

成功标准：

- 新玩家无需阅读说明即可完成选图、建塔、升级和开启下一波。
- 玩家能在开波前看到敌人构成与危险单位，并据此调整布阵。
- 每座攻击塔在 3 级时提供一次不可逆的双分支专精选择。
- 页面刷新后可以准确恢复当前波次、场上敌人、塔、弹道无关的持续状态及准备时间。
- 旧 V6 的生涯积分、最高波次、主题、速度、难度与最近关卡可迁移；V6 半局存档不迁移。
- 现有 V6 回归行为继续通过，新增 V7 核心行为具有自动化测试。
- 高压怪潮下粒子、音效与 UI 更新有明确预算，不随击中次数无限增长。

## 2. 范围

### 保留

- 4 张地图及其路径、配色和基础难度差异。
- 13 种塔、15 种敌人和现有技能机制。
- 1～5 倍游戏速度、5 档难度、明暗主题、键鼠与触屏操作。
- 生涯积分阈值、单图最高波次和本地离线存储。

### 新增或调整

- 塔分类栏、常驻战斗工具栏、暂停功能和波次预览。
- 11 种攻击塔的 3 级双分支专精；棱镜和方尖碑使用各自的支援专精。
- 完整 V7 续局存档与 V6 长期数据迁移。
- 修正敌人早期生命成长公式并重新校准前 15 波奖励。
- 粒子上限、音效节流、UI 脏标记和目标查询优化。

### 不做

- 联网排行、账号、付费、多人模式、关卡编辑器。
- 外部图片、字体、音乐或第三方库。
- V6 半局存档到 V7 的敌人级精确转换。
- 新地图、新塔或新敌人。V7 的新鲜感来自专精与信息设计，而不是继续堆数量。

## 3. 信息架构与界面

页面保持战场加侧栏的双栏结构。桌面端战场占剩余宽度，侧栏宽度约 320px；窄屏继续上下布局。

侧栏从上到下分为：

1. 紧凑资源条：积分、核心生命、能量、波次、塔数量。
2. 常驻战斗工具栏：暂停/继续、下一波、速度、四个主动技能。关键战斗按钮不再放在长列表底部。
3. 塔库：四个分类页签——基础、元素、重装、奇术。每张塔卡显示名称、价格、快捷键和当前是否买得起。
4. 选中面板：属性、索敌策略、专精、升级与出售。
5. 次要入口：选关、传承、图鉴、主题。

画布顶部显示本局核心状态和波次进度。准备阶段显示下一波预览：总数量、敌人图标汇总、BOSS/暴君/幽影/医疗兵等危险标签、清波奖励和倒计时。战斗阶段显示剩余敌人数及当前重点威胁。

暂停由按钮或 `P` 触发。暂停时停止模拟、倒计时和技能结算，但允许选塔、切换索敌、升级、出售、查看图鉴及传承；禁止建塔规则不变。空袭瞄准中按暂停会取消瞄准且不扣能量。

## 4. 塔专精

每座塔升到 3 级后必须在两个专精中选择一个，选择后立即生效并写入存档。未选择时塔仍可攻击，但不能升到 4 级。专精不增加新的按钮层级：选中面板中出现两张并排选项卡。

| 塔 | 专精 A | 专精 B |
|---|---|---|
| 箭塔 | 连射：每第 4 次攻击追加一箭 | 穿甲：对护盾、装甲和 BOSS 伤害提高 25% |
| 毒雾塔 | 扩散：中毒目标死亡时向邻近敌人传播剩余毒效 | 腐蚀：中毒目标承受来自所有塔的伤害提高 8% |
| 冰霜塔 | 冻结：连续命中同一目标可短暂定身 | 寒域：攻击伤害降低，但命中点产生小范围减速 |
| 炮塔 | 重炮：主目标和溅射伤害提高，射速降低 | 霰爆：溅射范围扩大，主目标伤害不变 |
| 回旋镖塔 | 锋刃：往返命中会叠加流血 | 回旋：返程速度提高且返程伤害增加 |
| 激光塔 | 聚焦：只命中少量目标但单体伤害递增更快 | 折射：射线末端向附近目标折射一次 |
| 电磁炮 | 超导：最多穿透 5 个目标 | 蓄能：连续未开火时逐步积累下一发伤害 |
| 棱镜 | 超频：攻速光环更强但范围缩小 | 广域：光环范围扩大且额外提供少量射程 |
| 处决巨剑 | 猎首：对精英、暴君和 BOSS 提高伤害，但仍不可处决 BOSS/暴君 | 收割：普通敌人的处决线额外提高 6% |
| 磁暴塔 | 强牵引：拖回距离提高 | 引力井：拖回后短暂降低目标移速 |
| 雷暴塔 | 风暴链：额外跳跃 3 次 | 雷击：跳跃次数减少，首个目标伤害提高 80% |
| 黑洞 | 奇点：范围缩小但中心区域伤害翻倍 | 事件视界：范围扩大并短暂减速敌人 |
| 方尖碑 | 复苏：回血冷却降低 | 壁垒：不再回血，改为周期性生成 1 层核心护盾 |

专精数值以清晰、可测试、不会形成无限循环为原则。毒雾“扩散”只传播一次，腐蚀效果取最高值不叠加；范围效果均受固定半径约束。

## 5. 数值与波次

V6 注释期望的生命成长是 `1 + max(0, wave - 10) × 0.1`，实现却在前 10 波使用了 0.1～1.0 倍。V7 明确采用分段曲线：

- 第 1～10 波：`0.55 + (wave - 1) × 0.05`，即 0.55～1.0 倍。
- 第 11～60 波：`1 + (wave - 10) × 0.1`。
- 第 61 波起：`6 + (wave - 60) × 0.05`。

该倍率再乘地图倍率和难度倍率。这样修复公式偏差，但不会把第一波直接提高到原来的十倍。

为抵消早期生命提高，第 1～5 波清波奖励提高 20，开局资金保持原值；第 6～15 波奖励沿用 `25 + wave × 2`。第 16 波起不额外补偿。平衡测试目标是在不使用主动技能的自动策略下，地图 1 / 难度 1 能稳定进入 35～60 波，地图 4 / 难度 3 能进入 15～30 波；该区间用于检测异常，不追求固定结果。

波次预览直接使用实际待生成列表统计，不另写一套推测公式。改变难度仅允许在选关和第 0 波准备阶段进行，第一波开始后难度锁定，避免同一波出现不同生命倍率。

## 6. 状态模型与存档

V7 使用 `elementalOutpost.v7` 键族：

- 主键：当前对局快照。
- `.settings`：主题、速度、难度、最近关卡、音效开关。
- `.best`：每张地图的最高波次。
- `.legacy`：生涯积分和迁移标记。

首次启动时只迁移 V6 的 `.settings`、`.best` 和 `.legacy`。如果 V7 键已存在则不覆盖。V6 主存档保留但不载入。

快照保存：地图、难度、积分、核心生命、上限、能量、护盾、波次、阶段、准备倒计时、待生成队列、生成计时、暂停状态、塔列表和敌人列表。塔包含类型、格坐标、等级、专精、索敌、冷却与累计投入；敌人包含类型、路径距离、生命、护盾、存活状态和所有持续效果计时。

弹丸、粒子、短时视觉效果、当前悬停、当前选中和音效不保存。恢复后弹丸清空，敌人和塔按存档状态继续；这最多损失一轮飞行中的攻击，不会删除整批场上敌人。

存档包含 `version: 7`。解析失败、字段缺失、类型错误、地图越界或坐标非法时，丢弃当前 V7 半局存档并回到选关，但保留长期数据。写入失败不打断游戏，只以短提示告知“本局无法自动保存”。

## 7. 内部结构

产物仍是单 HTML，但脚本按职责分区，避免继续把行为散落在 `Game` 中：

- `CONFIG`：地图、塔、敌人、难度、专精和技能纯数据。
- `Rules`：生命、波次数量、奖励、伤害修正和专精效果等纯函数。
- `Store`：迁移、校验、序列化和恢复。
- `Enemy`、`Tower`、`Projectile`：单个实体行为。
- `Game`：阶段切换、命令处理、实体更新和死亡/漏怪结算。
- `Renderer`：Canvas 绘制与视觉预算。
- `UI`：DOM 缓存、事件绑定和脏标记刷新。
- `SFX`：音效开关及节流。

模块仍位于同一闭包中，通过明确的方法传递状态，不引入打包工具。规则函数保持无 DOM 依赖，以便 Node 冒烟测试直接调用真实逻辑。

## 8. 性能策略

- 粒子总量上限 500；达到上限时优先丢弃新的普通命中特效，BOSS、技能和处决特效保留预算。
- 普通命中音效最多每 45ms 播放一次；同一模拟步中的多个命中合并。
- `live()` 不再每个动画帧重写全部状态，只在数值变化或至少间隔 100ms 时更新文本。
- 每个模拟步只计算一次棱镜光环缓存；塔变化、升级或专精改变时使缓存失效。
- 每个模拟步构建一次可见敌人列表和位置桶，塔从邻近桶中索敌；全图技能仍遍历全部存活敌人。
- 游戏速度仍使用固定时间步；浏览器掉帧时保留最大追帧限制，避免无限补帧。

## 9. 输入与可访问性

- 保留 `1-9 0 Q W E` 选塔、`Z X C V` 技能、`N/空格` 开波、`Esc` 取消。
- 新增 `P` 暂停/继续。
- 所有关键按钮具有可见的禁用状态、键盘焦点轮廓和文字提示，不依赖颜色单独表达状态。
- 触屏最小交互高度保持 40px；窄屏的战斗工具栏吸附在侧栏顶部。
- 动画不使用强烈整屏闪烁；时停和空袭保留低透明度覆盖效果。

## 10. 错误处理与边界

- 暂停、游戏结束、选关界面不能释放技能。
- 空袭瞄准时切换地图、暂停或游戏结束都会取消瞄准且不扣能量。
- 专精只能在 3 级且尚未选择时设置；非法专精值在读取存档时归零并要求重新选择。
- 腐蚀、减速、冻结和引力减速使用明确的合并规则，避免负速度和重复乘算失控。
- 敌人在同一模拟步被多次致死仍只结算一次奖励。
- 恢复存档时若生命为 0，直接进入游戏结束状态，不恢复为可继续状态。
- 所有敌人生命、路径距离、计时器和资源值在恢复时限制到安全范围。

## 11. 测试与验收

新增 `_v7_smoke.js`，继续使用轻量 DOM/Canvas 桩加载真实 HTML 脚本。执行顺序遵循测试先行：每个新行为先写失败测试并确认失败原因，再写最小实现。

自动化测试至少覆盖：

- V6 长期数据一次性迁移，V6 半局存档不迁移，V7 数据不被二次覆盖。
- 第 1、10、11、60、61 波生命倍率边界。
- 波次预览与实际生成队列完全一致。
- 第一波后难度锁定。
- 暂停冻结模拟但允许升级、出售和切换索敌。
- 13 座塔的专精选择约束、存档恢复和至少一个代表性效果；共享规则通过参数化测试覆盖全部配置。
- 完整敌人快照恢复，包括路径距离、生命、护盾、毒、减速、隐身和增益计时。
- 同步致死只结算一次。
- 粒子上限、音效节流和 UI 脏更新。
- 选关、对局、暂停、游戏结束和模态框渲染不抛异常。

保留并适配 `_v6_balance.js` 为 `_v7_balance.js`。平衡模拟使用固定随机数种子，输出各地图/难度的到达波次、塔构成和专精构成，使结果可复现。

人工验收包括桌面端与窄屏各完成一局：选择地图、建塔、三级专精、暂停操作、主动技能、刷新续局、游戏结束和重新开始。检查按钮无需异常滚动即可触达，文本不截断，画布坐标与点击位置一致。
