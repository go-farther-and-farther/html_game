# 雨夜便利店街角微缩场景 — 设计文档

- 日期：2026-09-25
- 类型：三渲二（Toon / 卡通渲染）三维微缩场景
- 主题：日式便利店街角 · 雨夜 · 无 UI · 可自由拖拽/旋转/缩放
- 技术栈：单 HTML + 本地 three.min.js（r147），离线可运行，无构建步骤
- 性能目标：桌面优先，高画质，60fps

---

## 1. 目标与气质

制作一个"雨夜便利店街角"的三维微缩场景，像一幕被定格下来的日本动画街角模型。

- 第三视角观察整个场景，可自由拖拽、旋转、缩放观看
- 整体像一个可收藏的微缩模型 / 小型景观，**没有任何 UI 界面元素**
- 地面为一个完整的正方形底座，所有元素都搭建在底座上
- 构图紧凑、层次清晰，小巧精致
- 三渲二卡通渲染，强调浓厚的日式二次元动画氛围
- 材质干净、轮廓明确，色彩柔和但富有夜景霓虹的层次感
- 室内明亮温暖、室外潮湿昏暗，形成鲜明对比
- 气质：安静、治愈、带一点都市夜晚孤独感但依然温暖

**不要人物。**

## 4. 渲染与材质系统（三渲二核心）

### 4.1 卡通渲染（Toon Shader）

- 自定义 `ShaderMaterial`，替代标准 PBR：
  - 漫反射光照量化成 **2-3 级**（亮部 / 中间 / 暗部），保留动漫"色块"感
  - 每片材质带 **轮廓线（outline）+ 边缘光（rim）**，暗部边缘微微提亮，模拟动画的"冷边光"
  - 霓虹辉光：招牌、灯箱、贩卖机、路灯用 **自发光（emissive）+ 径向渐变光晕贴图**（Sprite 或贴片），不做真实 bloom，保持"干净"
- 统一使用 `MeshBasicMaterial` 做发光体（招牌、灯箱、橱窗内暖光），保证夜间亮度稳定

### 4.2 轮廓线（反壳法）

- 每个 mesh 加一个 **背面放大 mesh**（BackSide，深描边色，scale ≈ 1.03-1.05），得到干净动漫描边
- 描边色按基色取深（如白墙 → 深蓝灰，暖黄 → 深棕），避免全黑死板
- 底座、街道、地面用"无描边"或"浅描边"，保持模型感

### 4.3 程序化 Canvas 纹理

全部 2D Canvas → `CanvasTexture`，零外部资源：

- 招牌：白底 + 绿/红/黄 + 日文"24H" + 店名
- 货架：商品色块（饮料、零食、便当）
- 海报：暖色促销海报
- 湿沥青：深灰 + 噪点 + 水渍
- 霓虹反光：画霓虹光斑（垂直渐变光柱）
- 地面导视、公告栏、交通标志

### 4.4 湿润反光（湿夜景）

- 地面：深沥青 + 程序化"水渍"贴图
- 假反光：街道/路面叠加一层 **霓虹光斑贴图**（招牌、路灯、贩卖机在湿地的倒影），垂直拉伸 + 轻微模糊
- 积水：圆形/不规则平面，**波纹动画**（扩散环 + 中心微闪）
- 斑马线：白色条纹 + 高反光（湿面反光）

### 4.5 灯光设计（暖冷对比）

- 室内：暖色点光源（2-3 个，色温 ~2700K），照亮货架、便当区、收银台
- 室外：冷蓝环境光（月光/夜空）+ 路灯暖光 + 招牌/贩卖机霓虹
- 全局：低强度冷蓝 ambient + 微弱暖色 fill，营造"湿冷雨夜"

### 4.6 色彩基调

- 室外：冷蓝、深青、暗紫（雨夜）
- 室内：暖黄、橙、白（灯光）
- 霓虹：招牌绿/红、贩卖机蓝/黄、路灯暖橙
- 整体柔和但层次分明，"小巧精致可收藏"

## 7. 动效清单

全部细微、克制，营造"静止而精致的三维微缩世界"：

1. **持续降雨**：`THREE.Points` 约 2000 粒子，斜向下落，带轻微风偏
2. **屋檐滴水**：雨棚边缘定时生成水滴，下落 + 溅起小涟漪
3. **地面积水波纹**：积水处扩散环 + 中心微闪，随雨滴落点随机触发
4. **招牌/灯箱闪烁**：轻微、不规律的亮度抖动（模拟霓虹老化）
5. **自动门偶尔开合**：周期性滑开/滑合，带缓动
6. **雨水沿玻璃滑落**：橱窗上雨痕缓慢下移（Canvas 纹理动画）
7. **路面反光**：积水反射灯光，随雨滴微闪
8. **交通信号灯**：微弱红绿切换（低频、低亮度，置于路口转角处）
9. **关东煮蒸汽**：柜台上方缓慢上升的半透明雾（可选）

## 8. 相机交互

- 自定义轨道控制：**拖拽旋转 / 滚轮缩放 / 双指缩放**（复用 pelican 项目的 pointer 事件方案）
- **无任何 UI 元素**（无 HUD、无按钮、无文字）
- 目标点：便利店中心（高度 ~1.5m），初始视角 3/4 俯视
- 旋转范围限制：俯仰角 0.18-1.45 rad，防止穿地/穿顶
- 缩放范围：3.5-26 单位
- **空闲自动旋转**：停止交互 2.5s 后缓慢自转（微缩模型展示感）。默认开启；通过代码常量 `AUTO_ROTATE = true` 控制（无 UI 开关）

## 9. 性能目标

- 桌面优先，高画质，帧率目标 **60fps**
- 雨滴 2000+ 粒子（1 次 draw call）
- 阴影：路灯 1-2 个柔和阴影（shadow map 1024×1024）；若帧率不足则降级为无阴影（仅靠光晕）
- 灯光：室内暖光 2-3 个 + 室外冷蓝 + 路灯/霓虹
- 纹理：全部程序化 Canvas，无外部资源
- 几何：合并静态几何，降低 draw call
