# 鹈鹕自由骑行 · 综合优化设计

- **日期**：2026-09-24
- **目标文件**：`pelican-free-ride.html`（单文件，Three.js 场景）
- **优化方向**：综合优化（手感 + 视觉 + 性能），桌面浏览器
- **方案**：A. 原位优化（保持单文件结构，不拆模块）

## 背景

现有游戏是一个 Three.js 场景：程序化 IK 鹈鹕骑自行车，环形世界（360×360），收集小鱼，Web Audio 音乐（欢乐颂）。当前版本功能完整，但存在以下可优化点：

- **性能**：130 棵树 × 4 mesh = 520 draw call；云 12×4≈48；鱼 18×3=54；每帧多次 `new THREE.Vector3`（IK 解算、方向向量、踏板位置）造成 GC 压力；像素比上限 2。
- **手感**：速度离散整数（2–14，按键跳档），转向瞬时生效，相机硬跟随无平滑，跳跃生硬。
- **视觉**：纯色背景无氛围，无风粒子，无蝴蝶，水花简陋。
- **玩法**：无里程记录，无碰撞，鱼种单一。

## 目标

1. 性能：draw call 从 ~700 降到 ~100，低配设备 FPS 提升。
2. 手感：操控从"按键跳档"变成"油门/刹车"连续手感，骑行更流畅。
3. 视觉：画面更有氛围，高速有"速度感"。
4. 玩法：收集有目标感（里程 + 双鱼种），有碰撞反馈。

## 约束

- 保持单文件 HTML 结构，不拆模块。
- 仅桌面浏览器（键盘操控，不加入触控）。
- 只加少量玩法增强，不引入新场景/NPC/天气/任务。

## 设计

### 1. 性能优化

| 项目 | 现状 | 优化 |
|------|------|------|
| 树木 | 130 棵 × 4 mesh = 520 draw call | 树干/三层树冠各用 InstancedMesh（130 实例），4 个 draw call |
| 云 | 12 组 × ~4 球 ≈ 48 draw call | 所有云球合并为 1 个 InstancedMesh |
| 鱼 | 18 条 × 3 mesh = 54 draw call | body/tail/eye 各 1 个 InstancedMesh，3 个 draw call |
| 向量 | 每帧 `new Vector3` / `V()` 多次 | 预分配复用，消除每帧 GC |
| 像素比 | `min(dpr, 2)` | `min(dpr, 1.5)` |
| 阴影 | 2048 PCFSoft | 保持（单光源，开销可接受） |

**预期**：draw call ~700 → ~100。

### 2. 手感优化

- **平滑加速/减速**：`↑/↓` 持续按住加速/减速（速度 2–14 连续变化，约 3 秒从低到满速），松开后缓慢回落到巡航速度 6。
- **转向平滑**：转向角速度 lerp 过渡；高速时转向更灵敏（保留 `SPEED/6` 系数）。
- **车身侧倾**：转向时车身向内侧倾斜（`rotation.z` 叠加侧倾角）。
- **相机平滑跟随**：相机位置用 lerp 跟随（`1 - exp(-k*dt)`），替代直接加 delta。
- **跳跃手感**：按住空格蓄力（最高 1.2 倍跳高），松开即跳；落地加轻微车身下沉动画。
- **碰撞反馈**：撞树时速度降 40%、车身轻微弹跳、播放"咚"声，不摔倒。

### 3. 视觉优化

- **渐变天空**：大型球体 + 顶点色渐变（天蓝→地平线浅黄），替代纯色背景。
- **太阳辉光**：太阳球加 Sprite 辉光（additive blending）。
- **风粒子**：高速时（>10）车身周围出现速度线（Points，1 个 draw call）。
- **蝴蝶**：3–4 只程序化蝴蝶（双翼扇动 + 曲线飞行），沿世界随机路径。
- **水花升级**：过池塘时多圈涟漪 + 小水珠粒子。
- **雾色匹配**：雾色与天空渐变一致。

### 4. 玩法增强（少量）

- **里程记录**：HUD 显示累计里程（km），`localStorage` 保存最佳里程。
- **树碰撞**：撞树减速 + 弹跳（不摔倒）。
- **双鱼种**：普通小鱼（1 分）+ 金色大鱼（3 分，发光更强），比例 70/30。
- **收集音效**：金鱼用不同音效，更醒目。

## 测试与验证

- **语法检查**：`node --check` 或 `check-syntax.cjs` 验证 JS 无语法错误。
- **浏览器实测**：无控制台报错；FPS 稳定；操控手感（加速/减速/转向/跳跃/碰撞）；视觉（渐变天空/辉光/风粒子/蝴蝶/水花）；收集（普通鱼/金鱼/音效）；里程记录（localStorage）。
- **draw call 检查**：`renderer.info.render.calls` 确认降到 ~100。
